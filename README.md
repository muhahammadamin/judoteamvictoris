# TEAM VICTORIS — сайт клуба дзюдо с админ-панелью (v2.1)

Фронтенд: **Vue 3 + Vite + Vue Router**. Бэкенд: **Node.js** без внешних зависимостей. Данные лежат в `data/db.json`, фото — в `data/uploads/`.

```
backend/    сервер: API, авторизация, хранилище, Telegram, SEO
frontend/   Vue-приложение (сайт + админ-панель)
data/       создаётся при запуске (делайте резервные копии)
```

## Запуск (Node.js 20+)

```bash
npm run install:all     # зависимости фронтенда
npm run build           # сборка в frontend/dist
npm start               # http://localhost:3000
```

При первом запуске пароль администратора печатается в консоль. Админка: `http://localhost:3000/admin`.
Разработка: `npm run dev:backend` и `npm run dev:frontend` в двух терминалах, затем `http://localhost:5173`.

**Обновление с прошлой версии:** положите свою папку `data` рядом с новым кодом, и база подхватится сама (недостающие поля добавятся).

| **Оформление** | цвета сайта: 7 готовых (красный, золотой, янтарный, синий, зелёный, фиолетовый, серебро) или свой в формате HEX, светлый оттенок, 5 тонов фона, предпросмотр |

## Цвета сайта

Вкладка **«Оформление»**: выберите готовый цвет (например, «Золотой») или задайте свой. Основной цвет меняет все линии, кнопки, рамки, номера, подчёркивания и акценты на сайте и в админке. Автоматически подбираются:
- светлый оттенок для надписей;
- цвет текста на кнопках (на золотом он тёмный, на красном — белый);
- предупреждение, если цвет слишком тёмный и будет плохо виден на фоне.

Цвета вставляются прямо в страницу на сервере, поэтому при загрузке нет «мигания» старым цветом. Тема входит в резервную копию.

## Номер телефона в заявке

Принимаются **только узбекские номера `+998 XX XXX XX XX`**:
- в форме префикс `+998` зафиксирован, дальше вводятся 9 цифр, они сами форматируются; можно вставить номер целиком в любом виде (`+998 90…`, `998…`, `0…`) — лишнее отрежется;
- отклоняются номера с неверным кодом (начинается с 0 или 1), из одинаковых цифр (`+998 90 000 00 00`) и последовательностей (`1234567`, `7654321`);
- те же правила проверяются на сервере, подделать запрос в обход формы нельзя;
- повторная заявка с тем же номером в течение 10 минут не создаёт дубль (защита от двойного нажатия);
- в лимит «5 заявок в час» попадают только принятые заявки, поэтому ошибка при вводе не блокирует человека.

Важно: проверка отсекает случайные и выдуманные цифры, но не доказывает, что номер существует и принадлежит человеку. Для этого нужно подтверждение по SMS, оно требует платного сервиса (например, Eskiz). Старые заявки с любыми номерами при восстановлении копии не теряются.

## Telegram

Теперь **настраивается в админке** (вкладка «Telegram»), файл `.env` не нужен:
1. В @BotFather создайте бота (`/newbot`) и получите токен.
2. Откройте бота и нажмите **Start**.
3. Вставьте токен, сохраните, нажмите **«Найти мой chat id»**, выберите свой чат, сохраните.
4. Нажмите **«Отправить тестовое сообщение»**.

Что исправлено по сравнению с прошлой версией:
- Токен хранится в базе (в админке виден только в маскированном виде), переменные окружения остаются запасным вариантом.
- Ошибки Telegram показываются понятным текстом (неверный токен, не нажали Start, нет прав, нет связи).
- Если заявка не дошла, она помечается в списке; сервер **сам повторяет отправку каждые 5 минут** (до 10 попыток).
- Можно указать несколько получателей и свой адрес API (если хостинг не достаёт до api.telegram.org).

## SEO

Мета-теги формируются на сервере, поэтому поисковики видят их без JavaScript:
- title, description, canonical, Open Graph, Twitter Card;
- JSON-LD: `SportsClub` (адрес, телефон, тренер, соцсети) и `FAQPage`;
- `robots.txt`, `sitemap.xml`, `noindex` для админки, переключатель закрытия сайта от индексации;
- Google Analytics и Яндекс Метрика; отправка заявки фиксируется как цель (`signup` / `generate_lead`);
- коды подтверждения Google Search Console и Яндекс.Вебмастера;
- gzip, кэширование, предзагрузка фона, текстовая версия для браузеров без JavaScript.

После публикации: укажите адрес сайта во вкладке SEO, добавьте сайт в Search Console и Вебмастер и отправьте `/sitemap.xml`.

## Публикация

Нужен хостинг с Node.js и постоянным диском (VPS, Render, Railway, Fly.io). Через Docker:

```bash
docker build -t team-victoris .
docker run -d -p 3000:3000 -v tv-data:/data -e ADMIN_PASSWORD=мойпароль team-victoris
```

Том `/data` обязателен. Поставьте перед сервером HTTPS (Caddy, nginx или встроенный HTTPS хостинга).

## Забыли пароль

Пароль нельзя посмотреть: он хранится в виде хэша и показывается только один раз при самом первом запуске. Зато его можно сбросить:

**Способ 1 — командой (сервер остановите: Ctrl+C):**
```bash
npm run reset-password                  # сгенерирует новый пароль и напечатает его
npm run reset-password -- МойНовыйПароль1   # или задаст ваш (минимум 8 символов)
npm start
```
Все прежние сессии при этом завершаются, заявки и тексты остаются на месте. Если сервер ещё запущен, команда откажется работать и подскажет остановить его.

**Способ 2 — переменной при запуске (удобно для Docker и хостингов):**
```bash
RESET_ADMIN_PASSWORD=МойНовыйПароль1 npm start
# Docker: добавьте -e RESET_ADMIN_PASSWORD=МойНовыйПароль1 и перезапустите контейнер
```
После входа удалите эту переменную, иначе при каждом запуске пароль будет сбрасываться заново.

Затем смените пароль на свой во вкладке **«Система»**.

> `ADMIN_PASSWORD` из `.env` действует только пока администратора ещё нет (самый первый запуск), поэтому на уже созданный пароль не влияет.

## Безопасность

Пароль хранится как scrypt-хэш, сессия — подписанная HttpOnly-cookie. Ограничение частоты: 5 принятых заявок в час, 30 попыток отправки в час и 10 попыток входа за 15 минут с одного IP. Токен Telegram никогда не отдаётся в браузер. Загрузка только JPG/PNG/WebP (проверка по содержимому). Идентификаторы аналитики и коды подтверждения проверяются строгими шаблонами. CSV-экспорт защищён от формул.
